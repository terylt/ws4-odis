# ODIS Router

A draft proposal for how the ODIS Router works: what it verifies, how it resolves the target of a call, what it sends to a policy engine, and how it enforces the decision. It is a proposal for discussion and is not part of the ODIS specification.

**To read it,** open [ODIS-Router.md](ODIS-Router.md), the whole document in one file.

**To change it,** edit the files in [sections/](sections/), then run `python3 build.py` and commit the regenerated `ODIS-Router.md` with your changes. `ODIS-Router.md` is generated, so edits made to it directly are lost the next time it is built. The reading order is set in [sections/order.txt](sections/order.txt).
